
 🌿 EcoMarket

EcoMarket es una plataforma web desarrollada con una arquitectura limpia y modular, diseñada para promover el consumo responsable y ofrecer productos ecológicos que cuidan el planeta y el bienestar de los usuarios.


 🛠️ Tecnologías Utilizadas

HTML5: Estructura semántica de las páginas.
CSS3: Estilos personalizados organizados por módulos (Flexbox y Grid para diseño responsivo).
Git y GitHub:** Control de versiones y despliegue del proyecto.

 📂 Estructura del Proyecto

El repositorio está organizado de forma limpia y desacoplada para facilitar su mantenimiento y escalabilidad:

text
EcoMarket/
│
├── Css/
│   ├── main.css          # Reseteo básico y variables globales
│   ├── layout.css        # Estructura general, Grid y Responsive Design
│   ├── components.css    # Estilos de tarjetas, botones, formularios y banner
│   └── animations.css    # Animaciones y transiciones de la interfaz
│
├── Img/
│   └── products/         # Imágenes de los productos ecológicos
│
├── Views/
│   ├── productos.html    # Catálogo completo con filtros
│   ├── sobre-nosotros.html # Misión y visión de la marca
│   └── contacto.html     # Formulario de contacto y atención al cliente
│
├── index.html            # Página de inicio (Home)
└── README.md             # Documentación del proyecto
